# ADR 0003: Админское редактирование реквизитов дела

## Статус

Принято; миграция подготовлена, применение к Production выполняется отдельно.

## Решение

Администратор организации может изменить только номер, название, описание и срок ответа
дела через `public.update_matter_details`. Server action повторяет валидацию формы, а
PostgreSQL RPC повторно проверяет текущую сессию, принадлежность дела и роль
администратора. Уникальность номера проверяется внутри транзакции, а триггер блокирует
прямое изменение этих четырёх полей неадминистратором.

Физическое удаление дела не добавляется. Для вывода дела из рабочих очередей используется
статус `archived`, поэтому связанные документы, сообщения и история остаются доступными
уполномоченным участникам.

## Последствия

- UI не дублирует логику прав: кнопка скрыта у юриста, но окончательное решение принимает БД.
- Обновление проходит через существующий триггер аудита и не записывает в журнал значения
  реквизитов.
- Для включения возможности в окружении нужно применить миграцию
  `20260829090000_add_matter_details_management.sql` после отдельного согласования.
